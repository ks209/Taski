# Taski 🚀

Taski is a modern all-in-one developer dashboard built for everyday productivity.
It combines essential developer utilities into a single clean interface so you don’t need to open 10 different tabs while working.
> Everything runs completely on the frontend with data stored locally using LocalStorage.

# ✨ Features

## 🧪 Developer Tools

### 🔐 JWT Decoder
Decode and inspect JWT tokens instantly.

### 🧩 Regex Tester
Test regex patterns with live match highlighting and captured groups.

### ⏰ Cron Evaluator
Preview upcoming cron schedules with timezone support.

### 📡 API Status Checker
Monitor API health endpoints and response times.

---

## 📊 Productivity Widgets

### 💧 Water Tracker
Track your daily hydration progress locally.

### 🎵 Embedded Media Player
Minimal music/player integration for focus sessions.

# ⚡ Local Storage Based

Taski does not require a backend.

All preferences, trackers, and tool states are stored directly in your browser using LocalStorage.

Benefits:
- Fast performance
- No authentication required
- Privacy-friendly
- Works instantly
